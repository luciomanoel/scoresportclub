SCORE SPORT CLUB

Política de Privacidade

Última atualização: novembro de 2026.

O que é este aplicativo

O aplicativo Score Sport Club é usado exclusivamente pelo próprio dono do canal Score Sport Club no YouTube para criar, atualizar e encerrar as transmissões ao vivo do canal, por meio da API de Dados do YouTube (YouTube Data API).

Dados acessados

O aplicativo acessa apenas a conta do YouTube do próprio canal, com a autorização do dono, para gerenciar as transmissões ao vivo (título, descrição, privacidade e playlists). Ele não acessa, não coleta e não armazena dados de espectadores ou de outros usuários.

Armazenamento e compartilhamento

A autorização concedida pelo Google fica guardada apenas no computador que gera as transmissões. Nenhum dado é vendido, compartilhado com terceiros ou usado para publicidade.

Serviços do Google

Este aplicativo usa os Serviços de API do YouTube. Ao assistir ao canal, valem os Termos de Serviço do YouTube e a Política de Privacidade do Google. O uso de informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google.

Como revogar o acesso

O acesso pode ser revogado a qualquer momento na página de permissões da Conta Google: myaccount.google.com/permissions.
